# AI Tools for Home Services Businesses

Two Python scripts using the Claude API to help small home services 
companies generate content and research leads.

## Tools
- content_generator.py — generates YouTube ideas, script outlines, 
  and Instagram captions from a given topic
- lead_researcher.py — identifies customer segments and generates 
  outreach messages for a given city and service type

## Setup
pip install anthropic
export ANTHROPIC_API_KEY='your-key-here'
python content_generator.py
